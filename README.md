# Fever Visual Assets

Ассеты клиента Fever Visual для Minecraft 1.21.11.

Архивы находятся в GitHub Releases. `manifest.json` содержит размеры и SHA-256 архивов и всех файлов.
Клиент использует закреплённую в сборке версию манифеста, скачивает архивы при первом запуске,
проверяет содержимое и сохраняет его в `<каталог игры>/fevervisual/assets`.
Проверенный кэш работает без интернета. Токены GitHub игрокам не требуются.

- `native-windows-x86_64.zip`: мост Fever DLSS, NVIDIA DLSS Super Resolution и Ray Reconstruction.
- `cosmetics.zip`: модели, текстуры оружия, крыльев, аватаров, питомцев и аксессуаров.

Драйвер видеокарты и системный Vulkan loader не распространяются и не заменяются.
Лицензия NVIDIA включена в архив библиотек. Исходные уведомления и авторство косметики сохранены
в наборах; права на сторонние материалы принадлежат их авторам.

Новая версия ассетов публикуется отдельным релизом. Существующие архивы нельзя подменять:
для новой версии обновляются манифест клиента и его сборка.
